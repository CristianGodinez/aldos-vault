# Aldo’s Vault

Prototipo académico de comercio electrónico para coleccionables. Esta versión está preparada para publicarse como sitio estático mediante GitHub Pages.

## Demo

El sitio incluye inicio, catálogo, búsqueda, detalle de productos, carrito guardado en `localStorage` y una solicitud de piezas por encargo simulada. No procesa pagos, no crea pedidos reales y no almacena datos de contacto.

## GitHub Pages

Los archivos públicos están en la raíz del repositorio y usan rutas relativas para funcionar correctamente en una URL de proyecto como `https://USUARIO.github.io/REPOSITORIO/`.

Para publicar manualmente en GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
